# LearnHarness для музыки (форк)

Форк [amosblomqvist/learnharness](https://github.com/amosblomqvist/learnharness) для изучения теории музыки: Formenlehre, Funktionstheorie, Tonsatz, каденции, немецкоязычные скрипты и их русские переводы.

## Что добавлено

Форк также включает все функции [MasteryHarness](https://github.com/wangdepin/MasteryHarness) (раздел «Из MasteryHarness» ниже) и свежий LearnHarness 0.6.1. Имя приложения, папка данных `%APPDATA%\LearnHarness` и путь установки остались прежними, поэтому граф и настройки сохраняются.

### Русский интерфейс

Интерфейс по умолчанию на русском. Переключить язык: Настройки → Общие → **Язык интерфейса** (English / Русский). Текст уроков, ответы учителя и ваши заметки не переводятся. Если какая-то надпись осталась по-английски, её можно добавить в `components/i18n/ru.ts`.

### Узлы графа на русском

Пока интерфейс русский, у каждого узла графа появляется русское название и описание. Немецкий или английский термин остаётся в скобках, например «Период (Periode)», а функциональные обозначения (T, S, D, D7 …) не меняются. Перевод делает Cheap-модель (Настройки → Агент) в фоне, порциями по 20 узлов. Пока он идёт, в правом верхнем углу графа видно, сколько узлов осталось. Узлы, которые уже по-русски, модель не трогает. Новые и изменённые узлы переводятся сами, когда граф обновляется.

Поиск по графу и по цепочкам находит узел и по русскому, и по исходному названию. В карточке узла внизу написан оригинал. Сам граф не меняется: исходные названия нужны экстрактору, чтобы не плодить дубли, а переводы лежат отдельно в `%APPDATA%\LearnHarness\data\graph\translations-ru.json`. Страница «Повторение» и карточки тоже показывают русские названия.

### Масштаб окна

**Ctrl + колесико мыши** увеличивает или уменьшает всё окно целиком, как масштаб страницы в браузере. Ctrl + = и Ctrl + − делают то же с клавиатуры, Ctrl + 0 возвращает 100%. Шаги от 50% до 300%, выбранный масштаб сохраняется между запусками. На графе Ctrl + колесико тоже масштабирует окно, а обычное колесико по-прежнему приближает сам граф.

### Интервальное повторение и напоминания

В форке три способа повторять, и все считают расписание по FSRS-6:

- **Review (из MasteryHarness).** Страница **Review** в боковой панели, под Practice, со счётчиком того, что пора повторить. Идеи, которые вы решали в Practice, возвращаются, когда их пора вспомнить. Отметьте нужные и нажмите **Start review**, чтобы открыть практику ровно по ним. Небрежная ошибка не считается забыванием. Если вы ошиблись в идее, которую знали хорошо, она помечается **re-check** и возвращается на следующий день.
- **Recall cards (новое в форке).** На той же странице кнопка **Recall cards** открывает выбранные идеи как карточки. На лицевой стороне название идеи: вспомните, что она утверждает, и откройте ответ (пробел). Затем оцените себя: **Again** (забыл), **Hard**, **Good**, **Easy** (клавиши 1–4). Оценка сразу переносит следующую дату повторения. Раздел **New ideas today** каждый день предлагает до 10 идей из графа, которые вы ещё не повторяли (например, из импортированных скриптов по Formenlehre). Кнопка **Learn as recall cards** запускает их. Модель при этом не вызывается. Esc возвращает на страницу Review.
- **Flashcards (плагин из LearnHarness).** Включается в Settings → Core plugins → *Flashcards*. Модель сама пишет карточки «вопрос → ответ» по выбранным идеям графа или по PDF/текстовому файлу и раскладывает их по колодам. Карточки можно писать и вручную (кнопка **+** у колоды). Повторение по колодам, до 20 новых карточек в день на колоду.

**Напоминания (новое в форке).** Внизу страницы Review есть настройка **Remind me daily…** с выбором часа (по умолчанию 9:00). Пока приложение открыто, даже свёрнутое, оно раз в день показывает системное уведомление «Time to review: N items are due». В это число входят идеи из Review и готовые карточки плагина Flashcards. Щелчок по уведомлению открывает Review. Если приложение было закрыто, уведомление придёт при следующем запуске после выбранного часа.

**Из терминала и Claude.** `learnharness review` показывает, что пора повторить, а `learnharness grade <id> <1-4>` записывает оценку. MCP-сервер даёт инструменты `review_due` и `grade_card`: в Claude Desktop можно попросить «погоняй меня по тому, что пора повторить», и Claude будет спрашивать идеи и сам записывать оценки.

Оценки recall cards лежат в `%APPDATA%\LearnHarness\data\review\cards.jsonl`, настройка напоминаний в `reminders.json` рядом.

### Из MasteryHarness

- **Coding questions (плагин).** Settings → Core plugins → *Coding questions*: учитель может давать упражнения с редактором кода и автотестами.
- **Вход по подписке вместо ключа API.** ChatGPT, Claude, GitHub Copilot, Grok или Google (через Antigravity: Gemini, Claude, GPT-OSS). Подключение: Settings → Keys → Subscriptions.
- **Закрепление и архив сессий.** Правый клик по сессии: Pin оставляет её наверху списка, Archive сворачивает в группу «Archived» внизу (поиск её находит). Новое сообщение возвращает сессию из архива.
- **Чтение по предложениям.** Текст урока можно читать по одному предложению (⌘/Ctrl+R), с озвучкой через ElevenLabs по желанию. Перезагрузка окна теперь Ctrl+Shift+R.
- **Цитаты при чтении.** Выделенный текст урока сам попадает в поле «Thinking while reading».
- **Темы.** Settings → Appearance: тёмные и светлые темы (Catppuccin, Gruvbox, Ivory, Pastel и другие) или своя.
- **Формулы как TeX.** Любую формулу KaTeX можно скопировать как исходник TeX.
- **Поля ответа.** Ctrl+Enter отправляет ответ, Enter переносит строку.
- **Материалы к уроку.** К уроку можно приложить PDF, EPUB, текст, картинки или ссылки (кнопка Sources на экране нового урока или во время урока). Материал задаёт цель урока, а учитель опирается на него и цитирует нужные места.
- **Значок прогресса.** Кольцо у сессии в боковой панели показывает, сколько плана пройдено.
- **Новый значок приложения** (буква M в виде графа).

### Импорт в граф («Extract files…»)

- **PDF, Markdown, TXT, а также RST, Org, AsciiDoc и TeX.** Лимит размера поднят с 25 МБ до 2 ГБ на файл (это практический потолок одной загрузки в память). Лимит в 1000 страниц PDF снят.
- **Картинки PNG, JPEG, WebP.** Vision-модель (слот *Vision* в Settings → Models) переписывает страницу в Markdown: текст, нотные примеры словами, функциональные обозначения (T, S, D, Tp, D7, DD …), цифровки, номера тактов, таблицы. Дальше текст идёт в граф обычным путём. Нотацию после распознавания стоит проверить.
- **Аудио MP3, WAV, M4A, AAC, OGG, OPUS, FLAC, WebM.** Расшифровка идёт через Deepgram (pre-recorded API, модель nova-3, язык определяется автоматически), нужен ключ Deepgram в Settings → Keys. Handy аудиофайлы не принимает, он работает только как живая диктовка.
- **Без дублей.** Файл, который уже успешно импортирован и с тех пор не менялся (тот же путь и то же содержимое, сравнение по SHA-256), при повторной загрузке пропускается с пометкой «Already in the graph; skipped.». Новые, изменённые и упавшие файлы обрабатываются. Если удалить источник из графа, он импортируется заново.
- **Понятная ошибка входа.** Вместо «not signed in» приложение пишет, что Claude Code не залогинен и что делать: открыть терминал, запустить `claude`, выполнить `/login` и перезапустить LearnHarness. Одинаковая ошибка больше не повторяется по разу на каждый кусок PDF.
- **Подсказки под теорию музыки.** Экстрактор сохраняет немецкие термины (с русским или английским эквивалентом, где это помогает), функциональные символы, цифровки и номера тактов в точности. Немецкую и русскую версии одного материала он считает одной мыслью. Учитель и практика получили фрагмент `shared/17-music-study.md`: немецкая терминология курса, ссылки на репертуар, задания в духе экзамена. Фрагмент можно переопределить в Settings → Agent → Prompts.

### Claude Fable 5.2

`claude-fable-5-2` есть в двух местах:

- **Claude Code** (`claude-code/claude-fable-5-2`) работает через вход в Claude Code, ключ не нужен;
- **Anthropic API** (`anthropic/claude-fable-5-2`) работает с ключом Anthropic.

Выбрать модель можно в Settings → Models для любого слота: Strong, Cheap или Vision.

### Диктовка через Handy

[Handy](https://handy.computer) — бесплатная офлайн-диктовка (Whisper/Parakeet на вашем компьютере).

1. Установите и запустите Handy (Windows: установщик с сайта или `winget install cjpais.Handy`).
2. Settings → Keys → Dictation → **Engine**. Варианты: `Auto` (Deepgram, если есть ключ, иначе Gemini, если есть ключ Google, иначе Handy), `Deepgram`, `Gemini` или `Handy`.
3. Кнопка **Dictate** (или ⌘/Ctrl+D) запускает запись в Handy, **Stop** останавливает её. Handy сам вставит текст в поле ввода.

Собственный хоткей Handy тоже работает: поставьте курсор в поле ввода LearnHarness и диктуйте. Если Handy установлен в нестандартное место, укажите путь к нему в переменной `LH_HANDY_PATH`.

### Диктовка через Gemini

Движок **Gemini** записывает голос в самом LearnHarness. Когда вы нажимаете **Стоп**, запись уходит в Gemini, и расшифровка попадает в поле ввода. В чат Gemini ничего не отправляется и нигде не сохраняется.

1. Создайте бесплатный ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Настройки → Провайдеры → API-ключи моделей → **Добавить ключ провайдера** → Google, вставьте ключ.
3. Там же, в разделе «Диктовка», выберите **Движок → Gemini (ключ Google)**. В режиме `Авто` Gemini включается сам, если нет ключа Deepgram.

Gemini понимает русскую речь вперемешку с немецкими терминами и сам расставляет знаки препинания. Язык из настройки «Язык диктовки» передаётся ему как подсказка. Длинные записи режутся на куски по 4 минуты, одна запись может длиться до 30 минут. Модель по умолчанию `gemini-flash-latest`, запасная `gemini-2.5-flash`. Другую можно задать переменной `LH_GEMINI_STT_MODEL`. На бесплатном тарифе Google может использовать запросы для улучшения своих продуктов.

Почему не сайт gemini.google.com: управлять сайтом из приложения можно только через скрытый браузер с вашим входом в Google. Это нарушает условия Google и ломается при каждом обновлении сайта. Официальный API использует те же модели Gemini и работает стабильно.

**Список надиктованного.** Каждая расшифровка (Gemini и Deepgram) сохраняется в Настройки → Провайдеры → Диктовка → **Надиктованное**: последние 30 записей с датой, кнопками «Копировать» и «Удалить». Handy вставляет текст сам, поэтому его записи сюда не попадают.

## CLI `learnharness`

CLI работает с запущенным приложением: тот же граф, те же модели и настройки. Десктоп-приложение пишет адрес и секрет в `%APPDATA%\LearnHarness\local-api.json` (macOS: `~/Library/Application Support/LearnHarness/`), а CLI читает их оттуда.

```bash
git clone https://github.com/UncleKnuckles/learnharnessmusik
cd learnharnessmusik
npm install
npm link            # команда learnharness станет доступна везде (или: node cli/learnharness.mjs …)

learnharness status
learnharness models                 # ★ отмечает Claude Fable
learnharness search Trugschluss
learnharness node n_abc123
learnharness import "D:\Musik\Formenlehre"      # папка: PDF, картинки, аудио, md
learnharness ask "Чем Periode отличается от Satz?"            # по умолчанию Fable 5.2
learnharness ask --model opus --effort medium "Was ist ein Trugschluss?"
learnharness review                 # что пора повторить + новые карточки на сегодня
learnharness grade n_abc123 3       # оценка карточки: 1 Again, 2 Hard, 3 Good, 4 Easy
learnharness doctor                 # проверка входа в Claude Code
```

`ask` вызывает `claude -p --model claude-fable-5-2` через ваш вход в Claude Code и подкладывает в контекст подходящие идеи из графа.

## MCP-сервер

`learnharness mcp` запускает MCP-сервер через stdio. Он даёт инструменты `graph_overview`, `search_ideas`, `get_idea`, `list_sessions`, `import_files`, `list_models`, `ask_tutor` (отвечает Fable 5.2), а также `review_due` и `grade_card` для повторения по карточкам.

Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "learnharness": {
      "command": "node",
      "args": ["C:\\path\\to\\learnharnessmusik\\cli\\learnharness.mjs", "mcp"]
    }
  }
}
```

Claude Code:

```bash
claude mcp add learnharness -- node C:\path\to\learnharnessmusik\cli\learnharness.mjs mcp
```

LearnHarness при этом должен быть запущен.

## Установка и обновления

Установщик лежит на странице **Releases** репозитория: https://github.com/UncleKnuckles/learnharnessmusik/releases/latest. Скачайте `LearnHarness-<версия>-x64-setup.exe` из раздела Assets и запустите.

Новый релиз собирается сам после каждого слияния в `main`, если в `package.json` поднята версия. Установленное приложение само скачивает новые версии и предлагает перезапуск (переключатель Settings → General → Automatic updates, там же кнопка Check for updates). Обновления форка берутся только из релизов `UncleKnuckles/learnharnessmusik`, поэтому релизы оригинала его не перезапишут.

Пересобрать текущую версию вручную: GitHub → Actions → **Windows installer (music fork)** → *Run workflow*. Файлы установщика в релизе этой версии заменятся.

Данные (граф, сессии, ключи) лежат в `%APPDATA%\LearnHarness` и не зависят от версии кода, так что после установки форка всё сохраняется.
